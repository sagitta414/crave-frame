# Hackathon submission checklist

Event: Build, Ship, Shape: Amazon Developer Hackathon.
Official requirements: https://amazonappdev2026.devpost.com/rules
Last requirements review: September 12, 2026. Submission deadline reviewed: October 23, 2026, 19:00 UTC. Recheck the official page before submitting.

## Proposed positioning

Crave Frame turns dinner and entertainment decisions into one adaptable evening. Fire TV is the recommended presentation direction if the actual-device demonstration is successful. The app is not a connected Alexa skill. An Alexa+ simulation is a distinct permitted route, not a claim that this application uses Alexa at runtime.

## Before submission

- [ ] Verify the public repository, complete editable source, license and fresh-clone setup.
- [ ] Record a public English YouTube/Vimeo demo under three minutes.
- [ ] For Fire TV, show the app operating on an actual Fire TV device or the accepted Fire TV/Vega simulator.
- [ ] Confirm current remote navigation, QR readability and phone sync on the target hardware.
- [ ] Complete the live AI evaluation, recording weak results as well as strong ones.
- [ ] Finalize the project description, primary track and any mini-challenge fields.
- [ ] Write factual product feedback for tools/APIs/SDKs actually used.
- [ ] Review assets and demo footage for rights and attribution.
- [ ] Explain changes made during the event window if the project predates the event.
- [ ] Check entrant eligibility and accept the official terms in the submission workflow.
- [ ] Submit and verify the receipt/status on Devpost.

The drafted demo and documentation are not evidence of a submitted entry. Gemini/Vertex usage does not establish AWS Builder participation. Optional friction logs can document genuine Fire TV/Silk navigation or onboarding issues; do not invent use of Amazon SDKs.
