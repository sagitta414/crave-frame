# Crave Frame TV application

Editable Expo / React Native TV source. See the [root README](../README.md), [setup guide](../docs/SETUP.md), and [testing guide](../docs/TESTING.md). Use the root build to serve the TV export and backend on one origin. Native SDKs and signing keys are intentionally excluded.

For the installed Fire OS app and synchronized phone cooking, see the [Windows build and device walkthrough](../docs/FIRE-TV-INSTALL.md). Confirm the device OS before installation; the APK does not support Vega OS.
